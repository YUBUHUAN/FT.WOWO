# 喔喔 · 桌宠

> 用你给的那张参考图做的 ENFP 小女孩桌宠。
> **Windows 原生桌面端 + 独立 Android App 共用云端账号：登录同一个账号，心情、投喂、运动、出游和陪伴时间实时互通，不再需要同一 Wi-Fi。**

![喔喔 · 桌宠](docs/images/hero.png)

## 她现在会的事

| | |
|---|---|
| **摸摸她** | 单击会回应一句 ENFP 式的、轻轻的台词；换时间、换心情，说的话也不一样。 |
| **连续戳** | 连按会变成「。」，按得越多「。」越长；戳太狠会晕、会轻轻抗议，停手后还会小声原谅你。 |
| **账号** | 第一次打开先创建账号，或登录已有账号。每个账号有独立的心情、饱食度、健康值、疲惫值、投喂/运动/出游记录，账号和密码绑定，密码只以加盐哈希保存。 |
| **投喂** | 奶茶、炸串、可乐、小蛋糕，以及**麻辣烫、巧克力、冰淇淋**。可选糖度、辣度、汤底、口味；她会用小女孩的口吻评价「太甜啦」「太辣啦」「太淡啦」。每次投喂会少量增加健康值。 |
| **出游** | 公园 / 游乐场 / 江边 / 旧书店，10 分钟或半小时。不同地点有不同对话；她按现实时间自己走完，关掉程序也不会作弊；回来会带一片叶子、一张车票、一段**路上遇到的小惊喜**，并写进手账，同时增加一点疲惫值。 |
| **运动** | 跑步 / 跳绳 / 散步 / 拉伸，3 / 5 / 10 / 30 分钟。运动时不能打扰她，但可以中断；点击显示「正在挥汗如雨」之类的状态，右键（手机点「让她停下」）可中断。健康值大量增加，疲惫值也明显增加，行为会写进主页。 |
| **健康与疲惫** | 健康值、疲惫值独立显示在手账里。吃太饱/运动过度/太累都有自己的状态；疲惫值会随休息慢慢恢复，疲惫太高时她会拒绝运动。 |
| **小屋背景** | 初始是温馨的「家」，点击主界面右上角的背景图标，可换成「窗边 / 雨夜 / 小花园」。背景跟着账号同步，电脑和手机会看到她待在同一间屋子里。 |
| **个人页面** | 心情值、饱食度、健康值、疲惫值、今日陪伴时长、累计被戳 / 投喂 / 运动 / 出游、周视图陪伴日历（可滑动/打开月历）、投喂记录、运动记录、出游手账、账号与同步、设置。 |
| **桌面感** | 无边框透明窗口、始终置顶、可拖动、透明区域点击穿透、托盘、开机启动、右键菜单。 |

## 马上运行（Windows）

打包好的程序在：

```
dist/WowoPet-Setup-1.6.0.exe        ← 给别的电脑装，带卸载器
dist/WowoPet-Windows-Portable/      ← 免安装便携版
dist/WowoPet-Android-1.6.0.apk      ← 安卓安装包
```

Windows 用户推荐直接运行 `WowoPet-Setup-1.6.0.exe`，会安装到 `%LOCALAPPDATA%\Programs\WowoPet` 并创建桌面/开始菜单快捷方式。便携版则解压后：

- **推荐**：双击 `启动喔喔.cmd`。它会带上随包的 .NET 运行时，不要求电脑预装 .NET。
- `启动喔喔.vbs` 是无窗口版；部分电脑禁用了 Windows Script Host，双击 VBS 会没反应——这时用 `启动喔喔.cmd` 就好。
- 也可以直接运行 `WowoPet.exe`（需要系统已安装 .NET 10 Desktop Runtime）。
- 轻量版（不附带 .NET 运行时）在 `dist/WowoPet-Windows/WowoPet.exe`，体积更小。

第一次启动会先出现**登录 / 创建账号**窗口。创建账号后会回到登录页，再输入一次密码即可进入：


登录后她才出现在屏幕右下角。以后会记住账号，直接进入。

如果 `启动喔喔.cmd` 打开后没有出现窗口，黑窗口会停住并显示原因；也可以直接双击 `WowoPet.exe`（需要系统已装 .NET 10），或把同目录的 `startup.log` 发给我。

> 账号、密码和宠物记录现在保存在 **Supabase 云端**；本地 `%LOCALAPPDATA%\WowoPet` 只保存登录 token、设置和离线缓存，升级/替换程序文件夹不会丢。旧版本地账号需要重新注册云账号。

## 账号与手机同步

Android 端是**独立的云 App**：安装后直接注册/登录，不再需要填电脑 IP，也不需要电脑和手机在同一 Wi-Fi。

- **APK**：`dist/WowoPet-Android-1.6.0.apk`
- **Windows**：`dist/WowoPet-Setup-1.6.0.exe` 或便携版

### 第一次使用

1. Windows 打开喔喔，创建账号（用户名 + 密码）。
2. 手机安装 APK，打开后直接登录**同一个账号**。
3. 电脑和手机都联网即可，电脑关机后手机也能继续用。

同步之后：

- 手机上喂她一杯奶茶，电脑上的健康值/心情几秒内会变；
- 电脑上带她运动或出门，手机上会看到倒计时和「挥汗如雨」；
- 陪伴时间会把两台设备的时间合在一起算（不会重复计算）；
- 账号、心情、投喂、运动、出游、小屋背景都存在云端。

> **每个账号的数据是独立的。** 退出账号后重新登录另一个账号，会进入另一间小屋。
> 云端只保存宠物状态和账号，不保存电脑文件；没有网络时会显示离线缓存，恢复网络后自动继续同步。
> APK / 安装包说明见 [docs/ANDROID.md](docs/ANDROID.md)。

| 炸串 🍢 | 不辣 / 微辣 / 中辣 / 特辣 / 孜然 / 甜辣 | 「特辣……你是想看我出丑吗？呜。」 |

| 小蛋糕 🍰 | 草莓 / 巧克力 / 抹茶 | 「抹茶有一点点涩。我喜欢这种不讨好的味道。」 |
| 麻辣烫 🍲 | 微辣 / 中辣 / 特辣 / 番茄 / 骨汤 | 「太辣啦——！这已经不是麻辣烫，是岩浆吧。」 |

## 她去哪里


| 地方 | 10 分钟 | 半小时 |
|---|---|---|
| 公园 🌳 | 心情 +8 左右，疲惫 +2 | 心情 +20 左右，疲惫 +5 |
| 游乐场 🎡 | 心情 +11 左右，疲惫 +2 | 心情 +26 左右，疲惫 +5 |
| 江边 🌊 | 心情 +9 左右，疲惫 +2 | 心情 +22 左右，疲惫 +5 |
| 旧书店 📚 | 心情 +10 左右，疲惫 +2 | 心情 +24 左右，疲惫 +5 |

不同地点有各自的**预览台词**和**出游中台词**；在手机上点「看看她」，或在电脑上点她，会听到那个地点专属的话。

出游是**按时间戳离线结算**的：她出门后可以关掉程序、关掉手机，回来再打开，时间照样走完。回来会有一张「出游手账」，记录她去了哪、待了多久、心情变化、带回来的小东西，以及**那只蹭过来的猫、那张旧车票、那个多给她一颗山楂的爷爷**之类的小惊喜。手账里会保留最近几次出游。

## 陪她运动




| 运动 | 3 分钟 | 5 分钟 | 10 分钟 | 30 分钟 |
|---|---|---|---|---|
| 跑步 🏃 | 健康 +3 / 疲惫 +10 | +5 / +17 | +9 / +27 | +20 / +54 |
| 跳绳 🤸 | 健康 +3 / 疲惫 +12 | +5 / +19 | +10 / +30 | +22 / +60 |
| 散步 🚶 | 健康 +2 / 疲惫 +5 | +3 / +9 | +6 / +16 | +14 / +32 |
| 拉伸 🧘 | 健康 +2 / 疲惫 +4 | +4 / +7 | +7 / +12 | +16 / +24 |

- 运动期间她会一边喘气一边轻轻跳，身上会冒汗、嘴边的话也会换；你点她，她会回应「正在跑步……汗水要滴到眼睛里了」之类的话。
- 右键（手机点「让她停下」）可以中断；提前停下只能拿到一部分健康值，但这次运动会被记录。
- 运动结束会出现一张「运动记录」，健康、疲惫、心情变化都写进手账。
- 疲惫值 ≥ 85 时她会拒绝新的运动；休息一段时间会慢慢恢复。

## 个人页面


- 心情环 + 心情标签 + 饱食度 / 健康值 / 疲惫值
- 今日陪伴分钟数、在一起第几天
- 累计被戳 / 投喂 / 运动 / 出游
- 陪伴日历：默认显示本周周一到周日，左右滑动/箭头查看之前的周；点日历可以看到所有日子
- 最近投喂记录（带她的原话和健康变化）
- 运动记录（含提前停下、健康/疲惫变化）
- 出游手账（地点、时长、心情、路上遇到的小惊喜）
- 账号与同步：当前账号、云同步状态、退出账号
- 设置：声音、始终置顶、开机启动、回到右下角、重新开始

主界面右上角的背景图标可以换小屋背景；手账里的陪伴日历可以左右滑动看之前的周，点「日历」能看到所有日子。


手机上的手账页是长滚动版，喂食、出游、运动和睡眠记录都可以点开查看。

## 数据是怎么互通的

```
┌──────────────────────┐        HTTPS / RPC        ┌──────────────────────┐
│  Windows 原生桌宠     │  ◄────────────────────►   │  Supabase 云端        │
│  WPF + 本地 Node 代理 │      账号 + 状态 JSON     │  账号 / 状态 / RLS    │
└──────────────────────┘                           └──────────┬───────────┘
                                                              │
┌──────────────────────┐        HTTPS / RPC                   │
│  Android 独立 APK     │  ◄──────────────────────────────────┘
│  内置 web/ + 云客户端  │        登录同一个账号
└──────────────────────┘
```

- **账号**：用户名 + 密码；云端使用 bcrypt 哈希，数据库里没有明文密码；登录后发随机 token，PC 存在 `%LOCALAPPDATA%\WowoPet\desktop-settings.json`，手机存在 `localStorage`。
- **数据隔离**：每个账号一行 `public.wowo_states`，心情/投喂/运动/出游/陪伴时间完全独立；所有访问都经过 `SECURITY DEFINER` RPC，表本身不直接暴露。
- **云端**：Supabase Postgres + REST/RPC，PC 和手机都能直接访问；不再依赖局域网。
- **PC 端**：WPF 原生窗口 + 本地 Node 代理，代理负责把账号/状态转发到云端；手机端断开电脑也能用。
- **手机端**：APK 内置 `web/` 和 `shared/` 资源，直接调用 Supabase RPC；没有电脑服务端。
- **陪伴时间**：服务端按心跳去重累计，两台设备同时开着也只算一份。
- **所有心情/饱食度/健康/疲惫/投喂/运动/出游数值**都由共享引擎计算，客户端只负责表现，避免两头各算一套。

## 云端数据在哪看

Supabase 项目：`cflewtmxgekfpusicnfx`

- 打开 Table Editor：https://supabase.com/dashboard/project/cflewtmxgekfpusicnfx/editor
- 打开 SQL Editor：https://supabase.com/dashboard/project/cflewtmxgekfpusicnfx/sql/new

三张表：

- `wowo_accounts`：账号 ID、用户名、bcrypt 密码哈希、创建时间（没有明文密码）
- `wowo_states`：每个账号的宠物状态 JSON、版本号 `rev`、更新时间
- `wowo_sessions`：登录 token 的 SHA-256 哈希和过期时间

在 Table Editor 里可以直接查看行；在 SQL Editor 里可以运行 `cloud/inspect.sql` 的查询，看账号和宠物状态概览。不要手动修改 `password_hash`、`token_hash` 或 `state`，否则可能损坏账号或宠物数据。删除账号可以用 `cloud/inspect.sql` 最后那条注释掉的 SQL（会级联删除状态和会话）。

发布用的 publishable key 只能调用 RPC，不能直接读表；表已开启 RLS，直接访问会被拒绝。数据库密码和 `service_role` 密钥不要发给别人。

## 从源码运行 / 重新打包

### 环境

- **.NET 10 SDK**（WPF，Windows）
- **Node.js 22+**（源码仓库不包含 265MB 的 `dist/` 和内置 `node.exe`；发布便携版前把 `node.exe` 放到 `desktop-native/node/node.exe`，或设置 `WOWO_NODE` 指向已安装的 node）
- **Python 3 + Pillow**（只在重新生成素材时需要）

### 本地运行

```powershell
dotnet run --project desktop-native/WowoPet.csproj
```

第一次运行会先创建账号。

### 只跑服务端 + 浏览器界面

```powershell
# 安装 Node.js 22+ 后
node server\server.js

# 浏览器打开 http://127.0.0.1:8788/
# 注册账号，或用同一个账号在另一台设备打开
```

### 重新发布便携版

```powershell
# 先把 node.exe 放到 desktop-native\node\node.exe，或设置 WOWO_NODE
powershell -ExecutionPolicy Bypass -File tools\build-native.ps1
```

会重新生成：

- `dist/WowoPet-Windows`：框架依赖版
- `dist/WowoPet-Windows-Portable`：带私有 .NET 运行时 + `启动喔喔.cmd` / `启动喔喔.vbs`

### 重新生成立绘素材

```powershell
python tools\prepare_assets.py
```

从 `assets-src/portrait.jpg` 去白底、羽化边缘、切头像和图标，输出到 `web/assets/` 与 `desktop-native/Assets/`（脚本会覆盖同名文件，再重新发布即可）。

### 测试

```powershell
node test\api-test.js          # 账号 / 数据隔离 / 投喂 / 运动 / 出游 / 持久化
node tools\capture.mjs mobile  # 用 Chrome 无头跑移动端交互并截图
node tools\capture.mjs auth    # 手机端登录界面
node tools\capture.mjs profile
```

## 已知限制

1. **云端同步需要联网**：APK 和 PC 都直连 Supabase；没有网络时会使用本地缓存，联网后自动同步。
2. **账号只在云端**：换设备登录同一个账号即可；云端项目由 `cloud/schema.sql` 初始化，账号和宠物状态都在 Supabase。
3. **旧本地账号不会自动变成云账号**：旧版是局域网本地账号，升级后需要重新注册一个云账号；旧宠物数据可以在后续版本做导入。
4. **系统表情**：Windows 的 WPF 会把 emoji 渲染成单色线稿（这正是当前视觉的一部分）；不同 Windows 版本的字体略有差异。
5. **桌面端只在 Windows 上测试**：WPF 窗口透明、置顶、穿透、托盘均按 Windows 10/11 实现。
